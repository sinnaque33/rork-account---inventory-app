# Yerel arşiv fontları

2026-10-15 tarihinde Google Fonts resmi deposundan indirildi; viewer çalışırken ağ bağlantısı gerekmez.

- [Roboto](https://github.com/google/fonts/tree/main/ofl/roboto): `Roboto[wdth,wght].ttf` → Roboto.ttf; SIL OFL, Roboto-OFL.txt.
- [Roboto Mono](https://github.com/google/fonts/tree/main/ofl/robotomono): `RobotoMono[wght].ttf` → RobotoMono.ttf; SIL OFL, RobotoMono-OFL.txt.

Android sistem fontunun sürümü cihazdan cihaza farklılaşabilir. Roboto Mono, kaynak monospace alias’ının sabit arşiv karşılığıdır; cihazdaki monospace fontuyla birebir eşitlik iddiası yoktur. Dosyaları üzerine yazmayın; yeni font sürümü için yeni ad kullanın.
